# CASSATION — 2:30 beat sheet (rehearsal checklist)

Content target 2:30; 0:30 structural slack to the 3:00 hard limit. Print this,
rehearse 3×: once live, once on hotspot, once forced-replay (hotkey `R`).
Full script + rationale: CASSATION-PLAN.md §7–8.

## Pre-flight (before stepping up)

- [ ] Server running, board blank, LIVE chip green, question copied to clipboard
- [ ] Judge card handed over; trackpad within judge's reach
- [ ] Hotspot pre-paired; phone unlocked; replay hotkey `R` tested on newest golden
- [ ] QR page known-good; timer visible to me, not the room

## Beats

- [ ] **0:00 Hook** — no slides, paste the BAs question, Enter.
  > "Before I burn a £400 GPU day on a candidate material, I have to know if the
  > literature number is real. Last month one wrong number cost me a weekend of
  > compute. This is Cassation."

- [ ] **0:12 Plan + strike (judge beat 1)** — decomposition streams in; hand over
  the trackpad.
  > "Strike any branch you like — it will never run."
  Judge strikes → row greys → judge clicks Approve. Don't rush their hand.

- [ ] **0:30 WOW 1: fan-out** — advocates ignite, counters climb.
  > "You're watching an afternoon of literature triage happen in twenty-five
  > seconds."

- [ ] **0:55 Skeptic wave** — red attacks green. While they search, gesture at the
  Docket wall (don't quote a number — say what's on the wall):
  > "Every case on that wall was tried today while I built this — each one a
  > replayable signed trace."

- [ ] **1:25 WOW 2: DISPUTED takeover** — full-bleed, two quotes, green→amber→red.
  Let the screen do the talking; name the finding in one line (Skeptic surfaced
  the Skeptic surfaces the counter-source: for big family batches the oven can
  win per portion — the "always cheaper" claim does not generalize.
  PLAN CORRECTION #2).

- [ ] **1:45 Jury (judge beat 2)** — jury panel opens.
  > "The agents can't settle this. That's the point — they don't get to."
  Rule for the newer measurement → "human-adjudicated" stamp → Judge re-plans in
  the same chain, one tie-breaker agent spawns. Point at it.

- [ ] **2:05 Verdict** — brief streams: chips, citations, struck branch ABSENT,
  ruling stamped, counters freeze. QR up:
  > "Open it on your own phone — tap any citation through to the primary source."

- [ ] **2:25 Close**
  > "Every event you watched is one line in a signed trace — here's the replay
  > key. A wrong number used to cost me a weekend; now it costs a Skeptic forty
  > seconds. And if you have a contested question of your own — we'll run it in
  > Q&A."
  *Only if the overnight job is genuinely running (plan §4 honesty rule — nothing
  in the codebase fires it; it must be started by hand and verified):* add
  > "The same question is running on Deep Research overnight as the appendix."

- [ ] **2:40–3:00 Slack** — absorbs one latency hiccup or a slow trackpad moment.
  Never fill it with new material.

## Fallback triggers (memorize all three)

1. **Wifi flaky / calls stalling** → toggle to hotspot, keep talking:
   > "Venue wifi is doing venue wifi things — fifteen seconds."

2. **Synthesis still streaming at close** → do NOT wait; close over the moving
   stream:
   > "The brief is still being written as we speak — the chips land as each claim
   > clears."

3. **Total API/network death** → hotkey `R` (replays newest golden trace, chip
   flips to REPLAY), acknowledge immediately and out loud:
   > "That's the network gone — one key flips us to a trace recorded this
   > afternoon, same UI, honestly labeled REPLAY. Your strike and ruling clicks
   > still work, and the trace file is on disk for inspection."

## Droppable beats (pre-agreed cut order if running long)

Docket mention → TTS stinger → QR phone beat. Never drop: strike, takeover, jury.
